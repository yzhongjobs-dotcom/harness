`Agent / Skill / scientific contract / existing Reviewer` 负责科学合理性、问题价值、重要性、创新性等科研判断；
`Controller / Validator` 仅负责状态、时序、schema、ID/hash、binding、Evidence identity、provenance 等机械约束，不承担科研内容判断。
（4）**最小充分修改**
只保留正常使用路径中真实存在、会导致以下后果的问题：

- 明显违反科研标准；
- 流程真实卡死或错序；
- 关键语义未进入实际执行路径；
- Evidence / 历史结果被错误复用；
- provenance、ID、hash、binding、lifecycle 等关键链路真实断裂。
  已有机制能够正确解决的，不修改。
  （5）**严禁防御性修改**
  **不允许任何防御性内容。只保留会真实阻断正常流程、产生明显语义冲突或明显不符合科研标准的问题。**
  不考虑恶意 Agent、极端绕过、异常人工篡改等情况，也不得为这些情况新增机制。
  不为理论完整性无故新增 `Stage / Gate / Hook / Reviewer / Registry / State / Artifact / parallel workflow`，不顺带重构无关模块。
