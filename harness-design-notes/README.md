# Harness Design Notes

这里保存用于设计和审查 Scientific Research Agent Harness 的过程资料，不属于任何单一科研项目。

- `ARIS_CORE_ANALYSIS.md`：对 ARIS 原始科研主链的分析和改造依据。
- `经验.txt`、`补充使用流程.txt`：用户对科研理念与 AI 执行架构的要求。
- `reference-paper-analysis/`：π0.5、DreamerV3、机器人超声、阻抗学习、触觉弹性成像等优秀论文的文本解析，用于提炼通用方法设计规律。

本目录只作为设计依据和历史记录；当前可执行规则以 `../ARIS/` 中的 Harness 为准。
